# books

Standard Fiori Elements application generated by the reusable `001 → 002` protocol.

## Service

- OData version: 4.0
- Service root: https://cc779debtrial-dev-bookshop-srv.cfapps.us10-001.hana.ondemand.com/admin/
- EntitySet: Books
- EntityType: AdminService.Books
- Key: ID
- Properties: createdAt, createdBy, modifiedAt, modifiedBy, ID, title, descr, author_ID, genre_ID, stock, price, currency_code

## Run

```bash
npm install
npm start
```

`npm start` opens the local FLP Sandbox at `test/flpSandbox.html` with the `books-display` intent. Use `npm run start-noflp` for the standalone `index.html` preview. The generated `ui5.yaml` reads the configured service through the Fiori Tools proxy. No backend or deployment change is performed.

## Validate

```bash
npm run lint
npm run build
```
